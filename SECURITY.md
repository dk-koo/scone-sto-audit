# Security policy

Version 0.2.0 is an experimental utility. The tool uses local files and does not make outgoing network requests. Do not commit or post confidential biomedical records, unpublished results, API tokens, license files or machine-specific paths. For a potential security vulnerability, contact the maintainer privately through their GitHub profile rather than opening a public issue with exploit or private data. Security fixes are reviewed as capacity permits; no response-time SLA is promised.
